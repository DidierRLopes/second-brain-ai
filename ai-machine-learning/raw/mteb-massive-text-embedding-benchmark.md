# MTEB: Massive Text Embedding Benchmark

**Source:** https://arxiv.org/abs/2210.07316
**Authors:** Niklas Muennighoff, Nouamane Tazi, Loic Magne, Nils Reimers (2023, EACL)

## Key Concepts

Comprehensive benchmark spanning 8 task types across 58 datasets and 112 languages: classification, clustering, pair classification, reranking, retrieval, STS, summarization, and bitext mining.

Key finding: no single embedding method dominates all tasks — the best model depends on the use case. MTEB provides an open leaderboard for comparing embedding models objectively.

## Impact

- Standard benchmark for evaluating embedding models
- Leaderboard drives rapid progress in embedding quality
- Revealed that task-specific evaluation matters more than single-number scores
