# The Llama Hitchhiking Guide to Local LLMs

**Source:** https://osanseviero.github.io/hackerllama/blog/posts/hitchhiker_guide/index.html
**Author:** Omar Sanseviero (Google DeepMind)

## Overview

Comprehensive guide covering quantization and fine-tuning for resource-constrained environments. Explains how QLoRA enables practical use of 4-bit quantized models on consumer hardware, with guidance on model selection, deployment, and optimization.

## Topics Covered

- Running LLMs locally: hardware requirements and model selection
- Quantization formats (GGUF, GPTQ, AWQ) and when to use each
- Fine-tuning on consumer GPUs
- Inference optimization techniques
- Practical deployment considerations
