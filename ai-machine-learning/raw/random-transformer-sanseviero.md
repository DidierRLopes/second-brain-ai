# The Random Transformer — Building a Transformer from Scratch

**Source:** https://osanseviero.github.io/hackerllama/blog/posts/random_transformer/
**Author:** Omar Sanseviero (Google DeepMind)

## Overview

Step-by-step transformer implementation from scratch using Python and NumPy, demystifying the math behind transformers. Covers encoder-decoder architecture, self-attention, multi-head attention, positional encodings, and greedy decoding with exercises and resources.

## Why It's Valuable

- Hands-on implementation helps build deep intuition
- No framework abstractions — raw NumPy for understanding
- Covers the full pipeline from input embeddings to output generation
- Includes exercises for deeper learning
