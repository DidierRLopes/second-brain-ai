# AI Agents from First Principles — Deep (Learning) Focus

**Source:** https://cameronrwolfe.substack.com/p/ai-agents
**Author:** Cameron R. Wolfe, Ph.D. (Netflix)

## Overview

Deep technical explainer on AI agent architectures, building from first principles. Covers the evolution from simple prompt-response to complex multi-step agent systems, including tool use, planning, and memory.

## Topics Covered

- What defines an AI agent vs a chatbot
- ReAct pattern and its variants
- Tool use and function calling
- Memory architectures for agents
- Planning and decomposition strategies
- Current limitations and open problems
