# papers/

This folder holds ~73 arXiv papers organized into thematic subfolders (see the layout in `../PAPERS_INDEX.md`).

The PDF files themselves are gitignored and not pushed — they're large (~210MB total) and every paper that matters is already cited, with its arXiv ID and a direct link, in `../PAPERS_INDEX.md` and the relevant `../ai-machine-learning/wiki/` articles. If you've cloned this repo, the folder structure and index are here, but you'll need to fetch the actual PDFs from arXiv yourself (the index links straight to each one).
